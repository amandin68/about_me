# about_me

Личный сайт — визитка. Чистый HTML и CSS, без сборки и зависимостей.

Опубликован через GitHub Pages: https://amandin68.github.io/about_me/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная — обо мне |
| `skills.html` | Технологии и навыки |
| `now.html` | Чем занят сейчас |
| `style.css` | Все стили сайта |
| `.nojekyll` | Просит GitHub отдавать файлы как есть, без обработки Jekyll |

## Как обновить сайт

```bash
git add .
git commit -m "Описание правки"
git push
```

Через полминуты изменения появятся на сайте.
